# Интернет-магазин с конструктором заказа, личным кабинетом и страницей оплаты

## Стек:  
HTML, CSS, TypeScript, React, Redux, Webpack

## Реализованные задачи:  
• Подключила роутер и реализовала маршруты в приложении.  
• Создала слайсы и подключила к ним данные из API.  
• Подключила данные к страницам и вывела с использованием компонентов из UI.  
• Реализовала механизм авторизации и защиты личного кабинета пользователя.
